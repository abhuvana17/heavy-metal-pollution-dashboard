## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Place Required Files
- Copy `heavy_metal_pollution_dataset.csv` to `pollution_dashboard/`
- Copy all trained artifacts into `pollution_dashboard/artifacts/`

### 3. Run the Dashboard
```bash
cd pollution_dashboard
streamlit run app.py
```

## ⚠️ Known Limitations & Honest Flags

1. **Synthetic data**: All 10,000 records are simulated — not from real environmental monitoring.
2. **High ML accuracy**: Expected artifact — Risk_Level is derived from PLI, which comes from the same metal features used as inputs (data leakage in a simulation sense).
3. **SHAP workaround**: If Gradient Boosting is the best model, LightGBM is used for SHAP (GradientBoostingClassifier doesn't support multiclass SHAP via TreeExplainer).
4. **LSTM temporal validity**: Dates are randomly assigned, so the LSTM learns data-generation patterns, not real longitudinal dynamics.
5. **Index thresholds**: HPI formulation, reference values, and PLI risk thresholds are project-defined, not official WHO/EPA standards.

## 🎓 Viva Summary

> "Our project is an AI-driven heavy-metal pollution prediction and environmental risk assessment system. We analyze Pb, Hg, As, Cd, and Cr across soil, water, and air using environmental and geographical parameters. Pollution indices (HPI, HEI, PLI) assess contamination, ML models (RF, XGB, LGBM, CatBoost, GB) classify pollution risk, SHAP explains predictions, and LSTM forecasts future trends.
